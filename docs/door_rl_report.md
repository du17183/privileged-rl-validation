# Panda Door：工装 GT 与价值加权重放的在线强化学习验证

## 实验问题与公平对照

目标是比较真实工装可提供的门角、角速度、把手位姿和接触位，能否在不进入部署 Actor 的条件下，提高 Panda 开门任务的在线样本效率。环境、奖励、示教、训练和评估 seed 在同一配对内保持一致。A/B/D 的 Actor 网络结构、初始参数及 step-0 评估相同；`results/door/pairing_validation.json` 提供逐 seed 检查。`results/door/actor_gt_isolation.json` 验证 A/B/D 推理时任意 GT 张量均不会改变动作。

| 组别 | Actor 输入 | Critic 输入 | 在线 replay |
|:--|:--|:--|:--|
| A | 26 维机器人观测 | 26 维机器人观测 | 均匀 |
| B | 26 维机器人观测 | 机器人 + 11 维工装 GT | 均匀 |
| C | 机器人 + 工装 GT | 机器人 + 工装 GT | 均匀；仅作 oracle observation 对照 |
| D | 26 维机器人观测 | 机器人 + 工装 GT | Critic 轨迹价值加权，20% 均匀底座 |

共享 1000 条成功的笛卡尔航点 + 差分 IK 专家轨迹。每个运行先做 3000 次 BC Actor 更新和 1000 次离线 Critic 更新，再进行 SAC 在线微调。32 个并行环境，每个向量步更新 4 次，batch 256，25% replay 来自共享专家数据，Actor BC 正则权重恒为 10。每组 5 个配对 seed，每个运行 500000 在线训练交互；每约 25000 在线步用 64 个独立于训练的评估回合测量成功率、回报及双指接触率。评估和示教采集交互单独计数，不混入横轴。复现参数见 `configs/door_experiment.json`。

环境调试的 32 条 pilot 示教与 seed 99 的 3000 步训练预检只用于接口验证，不进入上述 1000 条主示教及 5 seed 主统计；文件名中的 `pilot` 或 `seed99` 可与主实验区分。

主要样本效率指标为成功率曲线相对 500k 在线预算的归一化梯形 AUC。首次达到 50%、80%、90% 的交互步数按离散评估点报告；首次达标并不保证持续成功。每个组的均值、SD 及逐 seed 曲线保留在 CSV 和图中。B−A、D−B 的效应使用同 seed 配对差、配对 bootstrap 95% 区间与全部 2^5 种符号翻转的双侧 p 值描述。5 个 seed 的精确双侧 p 最小为 0.0625，因此不能单靠该检验在 0.05 水平宣称显著。

## 新 reset seed 的 checkpoint 复测

从主评估曲线为每个运行选择峰值 checkpoint（同分时取较早步数），并同时取 500k 终点 checkpoint，在此前未用于训练或选择的 reset seed 重新各评估 64 回合。40/40 次复测退出码为 0，额外消耗 1293504 次评估交互；逐运行结果见 `results/door/heldout_all.csv`，配对统计见 `heldout_paired_effects.csv`。

| 组别 | 峰值 checkpoint 复测成功率，均值 ± SD | 峰值 checkpoint 所在在线步数中位数 | 500k 终点复测成功率，均值 ± SD |
|:--|--:|--:|--:|
| A | 0.906 ± 0.162 | 375008 | 0.453 ± 0.505 |
| B | 0.694 ± 0.398 | 175008 | 0.000 ± 0.000 |
| C | 0.731 ± 0.292 | 350016 | 0.250 ± 0.433 |
| D | 0.566 ± 0.455 | 200000 | 0.166 ± 0.370 |

峰值 B−A 的配对复测差为 −0.213（bootstrap 95% 区间 [−0.506, 0.025]；精确 p=0.375）；终点 B−A 为 −0.453（bootstrap 区间 [−0.841, −0.066]；精确 p=0.125）。B 的部分早期峰值能在新 seed 上复现，但未转化为稳定的 500k 策略。该复测仍使用相同固定几何，只改变随机 reset seed，因此不是跨门型或真实机器人的泛化测试。

## 结论

**在这个 Panda Door 固定工位、1000 条闭环专家初始化与 500k 步 BC+SAC 协议下，没有证据表明训练 Critic 增加工装 GT 显著提高在线样本效率。** B−A 的成功率 AUC 点估计为 −0.094，精确配对检验 p=0.1875；B 虽在部分 seed 更早达到 50%，但 5/5 个终点均失败。D 的完整价值加权轨迹重放策略使已知成功 transition 被更频繁抽到，AUC 却比 B 低 0.040（p=0.5），也没有显示稳定收益。C 的结果同样受策略优化退化限制，不能用来否定「Actor 得到 GT」在更好训练方案下的潜力。

这回答的是本次仿真与训练配方的可行性问题，不证明真实工装 GT 普遍无效。下一轮应先解决 BC 到 SAC 的策略退化，再在相同配对预算下测试更强稳定化、变动门几何/初始条件、视觉观测和纯轨迹均匀重放对照。只有在这些条件下仍能复现 B−A 增益，才能将其归因于可迁移的工装真值优势。

## 机制解释的边界

Drawer 阶段 B−A AUC 为 −0.0208，95% 区间 [−0.1926, 0.1459]，精确双侧 p=0.7969。其失败原因不能从 A/B/C 曲线唯一确定。该固定工位中机器人关节、TCP 和时间可能部分推断抽屉位置；另外 SAC 的种子间方差和训练中退化都很大。这两点是待检验假设，不是已证明的因果解释。

Door 中 B−A 只改变训练 Critic 的 GT 输入，因此若出现收益，直接对应的是 Critic 训练路径；GT 也可通过 actor gradient 间接改变探索。A/B 数据本身无法把「价值估计改善」与「由价值梯度引发的探索变化」完全拆开。A/B/D Actor 没有显式的工装状态估计器；C 检查直接给 Actor GT 的 oracle 输入，但有限训练的 C 不构成数学意义上的最优上限。D−B 改变的只有在线轨迹重放分布，因而检验这一具体经验选择策略。接触曲线用于定位策略是否到达和抓住把手，不能单独证明价值估计准确性。

D 在轨迹之间按 Critic 价值加权、在轨迹内均匀取 transition；与 B 的逐 transition 均匀重放相比，它还改变了长短轨迹的相对权重。故 D−B 不能单独识别「Q 分数」的因果贡献，需要额外的轨迹均匀对照；本次只评价完整 D 策略。

周期评估挑出的最佳 checkpoint 将在新的 reset seed 上各复测 64 回合，并与最终 checkpoint 同时报告，防止把某一个短暂峰值误当作稳定策略。最佳 checkpoint 的选择仍使用主评估曲线，独立复测只用于检查选择结果，不回写训练或调参。真实工装还需要跨门型、把手、视觉、时延与 reset 故障的外部验证；本次结论限定在固定仿真工位和该 SAC 配方。
